Disaster Claims — Evaluation Dossier

A static review of the baseline classifier's real predictions on 179 held-out disaster-related claims from IFND. This is not a live system — there is no ingestion pipeline or geo-resolution running behind this page yet.

⚠ On the accuracy numbers below

The classifier scores 98.9% accuracy on this test set — but that number is inflated. IFND's source column predicts the label almost perfectly on its own (fact-checker outlets are ~100% "Fake," mainstream outlets ~100% "TRUE"), so the model has partly learned to recognize fact-check headline phrasing ("Fact Check: Video Shared As...") rather than the underlying truth of each claim.

Treat this dossier as a diagnostic of the classifier's current behavior, not a validated accuracy figure. The real test happens once this model runs against plain Reddit/Telegram posts, which won't carry fact-check-style framing.
